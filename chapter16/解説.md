# ボーナスの実行結果


以下のように`an-overloaded-container.cpp`からコンストラクタ`Container(std::initializer_list<float> )`を消去する。

```diff
struct Container
{
    Container(int,int)
    {
        std::cout<<"Two ints\n";
    }

-     Container(std::initializer_list<float> )
-     {
-         std::cout<<"std::initializer_list<float>\n";
-     }
};
```

実行結果

```sh
$ g++ an-overloaded-container.cpp -o p -std=c++17
$ ./p
Two ints
Two ints
```
