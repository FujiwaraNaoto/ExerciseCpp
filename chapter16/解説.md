# ボーナスの実行結果


以下のように`an-overloaded-container.cpp`からコンストラクタ`Container(std::initializer_list<float> )`を消去する。

```diff
struct Container
{
    Container(int,int)
    {
        std::cout<<"Two ints\n";
    }

-     Container(std::initializer_list<float> )
-     {
-         std::cout<<"std::initializer_list<float>\n";
-     }
};
```

実行結果

```sh
$ g++ an-overloaded-container.cpp -o p -std=c++17
$ ./p
Two ints
Two ints
```

# おまけ


```C++
// おまけ
int a=1,b=2;
Container c3{a,b};

```

intからfoatへの変換は縮小変換でありコンパイラによってはエラーになる場合がある。

```sh
$ g++ an-overloaded-container.cpp -o p -std=c++20
an-overloaded-container.cpp: In function ‘int main()’:
an-overloaded-container.cpp:23:18: warning: narrowing conversion of ‘a’ from ‘int’ to ‘float’ [-Wnarrowing]
   23 |     Container c3{a,b};
      |                  ^
an-overloaded-container.cpp:23:18: warning: narrowing conversion of ‘a’ from ‘int’ to ‘float’ [-Wnarrowing]
an-overloaded-container.cpp:23:20: warning: narrowing conversion of ‘b’ from ‘int’ to ‘float’ [-Wnarrowing]
   23 |     Container c3{a,b};
      |                    ^
an-overloaded-container.cpp:23:20: warning: narrowing conversion of ‘b’ from ‘int’ to ‘float’ [-Wnarrowing]
```

しかしながら定数式の場合`Container c2{1,2};`は`std::initializer_list<float>`でもエラーにならなかった


なぜか?
[List-initialization (since C++11)](https://en.cppreference.com/cpp/language/list_initialization)
のNarrowing conversionsに注目。

> List-initialization limits the allowed implicit conversions by prohibiting the following:
> conversion from an integer type to a floating-point type, except where the source is a constant expression whose value can be stored exactly in the target type

実行時にどんな値が入るかわからない変数ならエラーや警告で示すのが安全。
定数式なら値がわかっているので警告すら吐かない。

Notesに注目

> A brace-enclosed initializer list is not an expression and therefore has no type, e.g. decltype({1, 2}) is ill-formed. Having no type implies that template type deduction cannot deduce a type that matches a brace-enclosed initializer list, so given the declaration template<class T> void f(T); the expression f({1, 2, 3}) is ill-formed. However, the template parameter can otherwise be deduced, as is the case for std::vector<int> v(std::istream_iterator<int>(std::cin), {}), where the iterator type is deduced by the first argument but also used in the second parameter position. A special exception is made for type deduction using the keyword auto, which deduces any brace-enclosed initializer list as std::initializer_list in copy-list-initialization.

日本語訳
> 中括弧で囲まれた初期化リストは式ではないため、型を持ちません。例えば、decltype({1, 2}) は不正な構文となります。型を持たないということは、テンプレート型の推論では中括弧で囲まれた初期化リストに一致する型を推論できないことを意味します。したがって、template<class T> void f(T); という宣言がある場合、式 f({1, 2, 3}) は不正な構文となります。ただし、テンプレートパラメータはそれ以外の場合に推論可能です。例えば、std::vector<int> v(std::istream_iterator<int>(std::cin), {}) の場合、イテレータ型は最初の引数によって推論されますが、2番目のパラメータ位置でも使用されています。キーワード `auto` を使用した型推論については特別な例外が設けられており、コピーリスト初期化において、中括弧で囲まれた初期化リストはすべて `std::initializer_list` として推論されます。
