

# 実行結果

実行結果

```sh
$ g++ weakly-typed-strongly-puzzling.cpp -o p -std=c++17
$ ./p
1$
```

`g++ weakly-typed-strongly-puzzling.cpp -o p -std=c++17 -Wall -Wextra`をしても何も警告が出ない。

```
"" : 文字列リテラル
↓
!"" : boolでtrue(文字列リテラルがbool型に変換)が否定されるのでfalse
↓
!!"" : !でfalseが否定されてtrue
↓
+!!"" : trueが1の数字として解釈される
```


[Implicit conversions](https://en.cppreference.com/cpp/language/implicit_conversion)
