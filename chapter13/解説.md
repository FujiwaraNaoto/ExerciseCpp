# std::decayの解説

[std::decay](https://cpprefjp.github.io/reference/type_traits/decay.html)

機能
1. 参照を外す (remove_reference)
2. 配列→ポインタ、関数→関数ポインタ の変換
3. 残った最上位の cv 修飾を外す (remove_cv)


```sh
$ g++ omake.cpp -o p -std=c++17
$ ./p
Type = i # int
Type = i # int
Type = Pi # int*
Type = PFiiE # int(*)(int)
5
```


```C++
std::decay_t<decltype(ref)>(ref)
```
は`decltype(ref)`で`decltype(int&)`の意味．それを`decay()`するので`int`となる。

ちなみに参照を値にする時に使うことがある。値を参照にするのは意味なし。(需要がないからと思われる)
