# おまけ

そもそも`char`に`+`などの演算子が適用きるようにするのがそもそも間違いであるが，C言語由来の機能なので仕方がない。

ちなみに競技プログラミングのテクニックとして、`char`に演算子が適用できることを利用して大文字小文字相互変換を`('a'^'A')`のxorを用いて実現する手法がある。以下がその例。

```sh
$ g++ omake.cpp -o p -std=c++17
$ ./p
hELLOwORLD
HELLO WORLD! # std::toupper()
hello world! # std::tolower()
```


なぜこれが成り立つかというとASCIIでは大文字と小文字の下位5bitが完全に一致するように意図的に設定されているからである
```
'A' = 0x41 = 0100 0001
'Z' = 0x5A = 0101 1010
'a' = 0x61 = 0110 0001
'z' = 0x7A = 0111 1010
```

逆にASCII以外なら前提が崩れるため注意が必要。
