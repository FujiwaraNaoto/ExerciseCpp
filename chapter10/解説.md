`a-strange-assignment.cpp`中にあるように以下のようなコードを書くことは基本的にない．
```C++
std::string name{"Bob"};
getName() = name;
```

あえて書くならomake2.cppみたいに返り値を参照型にして代入するようなコードを書くことがあり得る。
しかし，わざわざそのようなコードを書く必要もない。
```C++
Person& getName(){
    static Person person{"Alice", 30};
    return person;
}
```

omake2.cpp実行結果
```sh
$ g++ omake2.cpp -o p -std=c++17
$ ./p
Before assignment: Alice, 30
After assignment: Bob, 25
```


# 参考

[値のコピー省略を保証](https://cpprefjp.github.io/lang/cpp17/guaranteed_copy_elision.html)



> C++17では、このようなコピー省略を保証する仕組みが導入される。そのため、オブジェクトの初期化のために使用するprvalueは、コピーもムーブもできない型であっても、関数の戻り値として返せるようになる。つまり、NRVOと区別してRVOの場合は、コピーコンストラクタを用意しなくてもよくなった。NRVOは依然として保証がないことに注意。
