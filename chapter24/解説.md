
# 実行結果

normal function

2は**1の明示的特殊化(explicit specialization)**で`template<>`はテンプレート引数を全て具体的に決めた版を書くという意味。
`template<T>`は「テンプレート引数を全て具体的に決めた範を書く」という意味なので新たに`template T`を宣言する必要はない。

```C++
template<>
void serialize<const std::string>(const std::string&);
```
